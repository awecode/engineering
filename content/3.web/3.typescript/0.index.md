## Setup

We recommend using a Unix-based operating system (e.g., macOS, Linux) for development. Windows is not recommended at all, not even WSL or VMs.

### For Web Development

Before you begin, make sure you have the following installed:

- [Node.js](https://nodejs.org/en/):
  - Try to use the latest LTS version.
  - We recommend using [asdf](https://asdf-vm.com/) to manage Node.js versions.
- [pnpm](https://pnpm.io/):
- [Python](https://www.python.org/):
  - We recommend using [virtualenv](https://virtualenv.pypa.io/en/latest/) to manage Python environments.
- [Git](https://git-scm.com/):
  - We recommend using [GitHub CLI](https://cli.github.com/) for interacting with GitHub.
- [Visual Studio Code](https://code.visualstudio.com/)
  - We recommend using the [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) for linting as well as formatting (more on this later).
  - You can use your preferred editor, but make sure it supports ESLint.
